# Confidentiality and Fictional Data Policy

All DevGuard examples, fixtures, tests, screenshots, terminal recordings, and demo assets use fictional data only. The Book and digital-library fixture domain is invented solely to demonstrate deterministic DevGuard behavior.

Fixture data does not originate from an employer or client. This repository includes no proprietary source code, API contracts, credentials, business rules, internal documentation, or private repository content.

Users are responsible for having authorization before analyzing any repository with DevGuard. Generated reports may contain repository-derived metadata or diagnostic evidence and should be reviewed before public sharing.
